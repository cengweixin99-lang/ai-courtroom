# 法源导入区

此目录接收官方法源快照。开发阶段允许先记录官方在线来源、核对日期和所用条款快照；面向外部发布前再补齐不可变文件哈希和独立法律复核。

每次导入至少记录：法域、法律文件名称、条款号、生效起止日期、效力状态、官方 URL、原文快照、来源类型、效力层级、核对人和核对时间。生产来源另须记录版本哈希。旧版本必须保留，禁止覆盖更新。

`source_manifest.json` 是 M3.1 的开发索引清单，只允许其中显式批准的条款进入
Elasticsearch。清单同时记录发布阻断项，不得将“可用于开发检索”解释为“允许生成
现实法律结论”。

`snapshots/npc-criminal-law-20201226.pdf` 应为国家法律法规数据库《中华人民共和国
刑法》记录 ID `ff808181796a636a0179822a19640c92` 的官方快照。当前工作区缺少该文件，
因此清单明确将其列为发布阻断项；恢复文件后索引器会校验 SHA-256。

`embedding_models.json` 是法律向量模型档案。环境变量中的 Provider、模型 ID、版本和
维度必须完整匹配档案；候选状态只允许离线索引与 Eval，不能绕过档案直接启用 API。
