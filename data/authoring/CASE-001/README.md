# CASE-001 青禾影像器材失窃案

本案为完全虚构的教学模拟案卷。人物、机构、地点、账号、设备编号和事件均不对应现实主体。

## 案件定位

- 案由草案：盗窃罪
- 核心条文：用户提供的《中华人民共和国刑法（2024版）》第二百六十四条
- 核心争点：行为人身份、取走行为、是否具有非法占有目的、数额或其他入罪情节
- 训练时长：约 25 分钟
- 假定法域：中华人民共和国，上海市一审（澄明区及其法院均为虚构）
- 当前状态：`DEVELOPMENT_READY`

## 数据边界

`author_only/ground_truth.json` 仅用于案卷设计和 Eval，禁止进入任何庭审参与者、Agent、法律分析器或前端上下文。运行时只可加载经审核后发布到 `data/releases/` 的版本。

用户提供的全国人大官网首页指向国家法律法规数据库。项目已定位并核验《中华人民共和国刑法》官方详情记录，保存其官方数据库下载快照和 SHA-256；第十三、十四、十七及二百六十四条已进入正式实体法来源。2009 公报版本保留为历史法源，威科先行 2023 修正版仅保留为交叉比对材料。

开发基线另采用法释〔2013〕8号第1、4条和《中华人民共和国刑事诉讼法》第50、51、55条。本案估价为12800元，高于司法解释允许各地确定的“数额较大”标准上限3000元，因此上海具体地方标准不影响E0结论。非法占有目的被建模为需要双方围绕证据论证的事实推断，不伪造一条不存在的独立法条。

`DEVELOPMENT_READY` 表示可以进入 E1 开发、联调和内部演示；不等于生产法律产品获批。专业法律复核被保留为对外发布门槛，不阻塞开发。
